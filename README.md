# 离开小岛的我 / Leaving the Island

一个用 Godot 4.7.2 做的中文像素风剧情游戏原型：塞尔达式的轻战斗 + FF7 式的世界地图 + RPG Maker 式的对话演出。

**但这不是一个游戏发布仓库。**

这是一次实验记录：**只给 AI 一段剧情，不给任何代码、美术、框架，看它一天之内能独立做到什么程度。**

---

## 实验条件

| 谁 | 做了什么 |
|---|---|
| **人** | 提供剧情口述、拍板方案、验收。仅此而已。不写一行代码、不摆一个场景、不画一张图。 |
| **ZCode** | 能操作电脑的编码代理。自己开编辑器、写场景、写 GDScript、跑测试、截图自查、改 bug。 |
| **GLM-5.3-Flash** | 驱动 ZCode 的模型。全程这一个模型。 |
| **网络** | 素材是 AI 自己去 itch.io 一类站点找的，自己解压、自己切图、自己对尺寸。 |

原话的记录在 `Zcode工作区域/00_思考过程/2026-10-31_用户口述设定与第一轮问答.md`——用户只说了"主角是飞行员、坠机失忆、以为自己是岛民、岛是实验岛、全员撤离"，剩下的推论、补洞、定人物，全是 AI 自己做的。

| 项 | 数量 |
|---|---|
| 场景 | 28 个 `.tscn` |
| GDScript | 50 个（不含插件） |
| 测试场景 | 10 个 |
| 冒烟测试 | 最终 **73/73 PASS** |
| 剧情 | 序章 → 上山 → 真相 → 双结局，方案文档 v1.1 全部内容做完 |
| Android | debug APK 打通，签名验证通过，43MB（本仓库不含产物） |

自认为最不像"AI 堆出来的 demo"的三处：

- **透明镇民**：镇民全是主角幻想出来的，半透明但**手持物不透明**——抱着的木箱、扫帚会悬浮飘动。这条设定是 AI 从"全员 36 人撤离、名单上没有他"推出来的。
- **夜里的人格**：夜里的"他"知道全部真相、蓄意引爆火山撑开电磁风暴，靠日志和录像揭示，主角全程不知道。这是 AI 补的洞——原设定里"为什么火山会爆发"是空的。
- **时间线自洽**：主角 22 岁坠机、岛上住了 2 年、现在 24 岁；撤离发生在坠机**之前**，所以他记忆里的童年全是脑补。AI 用一个等式（22+2=24）把原稿里三处矛盾一次性焊死了。

## 怎么读这个仓库

1. **`交接文档.md`** —— 先看第 0 节「用户协作规则」和第 2 节「剧情正典」，你会知道这是一个什么样的项目。
2. **`Zcode工作区域/03_会议记录/`** —— 按文件名时间顺序读，八篇，能看出它是怎么一轮轮推进的。
3. **`Zcode工作区域/00_思考过程/`** —— 剧情通读笔记和两轮问答，能看到它读完全文后提了哪些问题、推了哪些结论。
4. **`离开小岛的我/scenes/`** —— 代码本身。

## 美术素材：能跑，但是占位图

这个仓库**打开就能运行、能继续编辑**，但画面不是最终样子。

原因是版权，不是偷懒。项目当初用的素材分三类：

| 类别 | 处理 |
|---|---|
| **允许再分发的**（Kyrise 图标 CC BY 4.0、Tiny RPG 地形、Fusion Pixel 字体 OFL、两个 MIT 插件） | ✅ 原样随仓库提供，已署名 |
| **不允许再分发的**（Pipoya 角色与地图、Cainos 地形、Village TopDown） | 🔲 换成**同文件名、同尺寸**的占位图，共 569 张 |
| **AI 自己画的**（28 张道具 + 8 张地块） | ✅ 原样保留，生成脚本在 `06_工具脚本/` |

占位图长这样：角色是深色小人剪影（朝下两只眼、朝左右一只眼、朝上没有脸），地块是带边框的色块棋盘。

**为什么要保持同尺寸**：TileSet 的图集坐标、角色表的分帧参数全都依赖像素尺寸。尺寸一致，工程就不用改任何一行；你想换回真素材，把原文件按同名同路径盖回去、重新导入即可，步骤写在 `素材还原指南.md`。

想看它真正长什么样：`Zcode工作区域/00_思考过程/` 里有游戏截图，Releases 里有能直接跑的构建。

## 剧情来源

故事原型是作者 2023 年 6 月写在本子上的一个短篇（`离开的我/孤独之岛·日记原文.md`），后来扩写成八章小说。AI 拿到的是口述设定，不是原文——它得自己从口述里推导出时间线、人物动机和世界观。
