# 《最后离开的我》协作指南（给人工调整用）

> 2026-10-31 · 随重构完成而写。原则：**凡是数值和摆放，都不需要改代码**。
> 本轮新增：触屏操作 / 世界地图 / 演出导演（见文末三节）。

## 一、打开工程后你会看到什么

用 Godot 4.7.2 打开 `离开小岛的我/project.godot`，文件系统面板的关键目录：

```
scenes/
├── main/          主菜单
├── town/          小镇（核心场景）
│   ├── town.tscn        ← 游戏实际加载的小镇（全部可编辑！）
│   ├── town_build.gd    ← 建造脚本（只在重新烘焙时用，见下文四）
│   └── town_tiles.tres  ← 地块集资源
├── actors/        角色（player / boar / villager / pickup / 石子弹）
├── props/         道具（house / tree / well / sign_post，全部 @tool 可实时预览）
└── ui/            界面（hud 血条计 / backpack 背篓 / dialogue_balloon 对话框）
assets/            素材（sprites / tilesets / ui / audio / fonts / shaders）
resources/dialogue/  对话脚本（.dialogue 纯文本，记事本就能改）
tests/             冒烟测试 + 烘焙运行器
```

## 二、小镇场景树（town.tscn 打开后）

```
Town
├── Ground            地面 TileMapLayer（地块已画好，可用瓦片画笔直接改）
├── World             ← 一切有 Y 排序的东西（前后遮挡自动处理）
│   ├── Buildings     5 栋房子（House_我家 / House_陈婆小卖部 / House_会堂…）
│   ├── Trees         全部树（Tree_000 ~ Tree_1xx，一棵一个节点）
│   ├── Fences        菜地栅栏（每格一个节点）
│   ├── Props         井台(SaveWell_井台)、木牌、码头
│   ├── NPCs          陈婆 / 大婶 / 狗子
│   ├── Enemies       野猪 ×3
│   ├── Pickups       地上的橘子糖/石子
│   └── Player        玩家（含相机）
├── Walls             看不见的墙（上下左右边界+水域碰撞，名字都标了）
└── NorthExit         北出口提示区
```

**想挪树/房/NPC？** 直接在视口里点选拖拽，或改检查器里的 position。Y 排序会自动适应。
**想挪碰撞框？** 选中节点里的 Shape 子节点改大小/位置（房子用检查器里的 collider_size/collider_offset 更方便）。
**看不见的墙在哪？** Walls 容器里名字都写着（Wall_水左/Wall_上…），选中后视口里有半透明框。

## 三、数值在哪里调（检查器 Inspector）

选中节点 → 检查器里全是带中文注释的参数，改完直接跑：

| 想调什么 | 选中谁 | 参数 |
|---|---|---|
| 玩家移速/走路动画快慢 | World/Player | 移动·move_speed / walk_fps |
| 玩家血量/挥砍时长/三段伤害/无敌帧/击退 | World/Player | 战斗·max_hp / attack_time / attack_damages … |
| 野猪血量/冲撞速度/发现距离/掉落 | World/Enemies/Boar_x | 数值·max_hp / charge_speed / detect_radius … |
| NPC 名字/对话/巡逻路线/移动速度 | World/NPCs/NPC_x | 身份·dialogue（把 .dialogue 文件拖进来）/ 巡逻·patrol_points |
| 透明度 | NPC 的 Sprite 材质 | shader_parameter/alpha（0~1） |
| 房子换贴图/碰撞 | World/Buildings/House_x | house_texture / collider_size（编辑器实时预览） |
| 树换贴图 | World/Trees/Tree_x | tree_texture |
| 木牌文字 | World/Props/SignPost_北出口 | sign_text |
| 血条颜色/位置 | scenes/ui/hud.gd | （M4 再做成导出参数） |
| 全局输入按键 | 项目设置 → 输入映射 | attack/interact/backpack… |

## 四、两种改地图的方式（重要：别混用）

- **方式 A（推荐日常用）**：直接在编辑器里改 `town.tscn`——拖树、补房子、画地块，保存即可。
- **方式 B（批量重建用）**：改 `town_build.gd`（ASCII 地图/摆放逻辑），然后命令行重烘焙：
  ```
  D:\godot\Godot_v4.7.2-stable_win64.exe --headless --path 离开小岛的我 res://tests/bake_town.tscn
  ```
  ⚠️ **重烘焙会整体覆盖 town.tscn**，方式 A 做的手工调整会丢。要么先备份，要么把手工改动同步回 town_build.gd。

## 五、对话怎么改

对话按**场景分文件夹**：`resources/dialogue/town/`（小镇）等。当前文件：
- `town/chenpo.dialogue` 陈婆（初见/重访分支）
- `town/laoxiaozhang.dialogue` 老校长（含阿豆跑过来的演出事件，解锁火山口flag）

纯文本，记事本可改。语法（Dialogue Manager）：
- `~ 标题` 章节标题；`陈婆: 台词` 说话；`- 选项 => 跳转` 选项
- `do Inventory.add_item("candy", 2)` 发道具；`do Game.set_flag("xxx", true)` 置剧情标记；`if Game.get_flag("xxx") == null` 条件分支
- **演出指令**（对话里直接写，NPC 走到位才说下一句）：
  - `do StageDirector.move_npc("NPC_阿豆", "NPC_老校长", Vector2(-44, 0), 150.0)` 让谁走到谁身边
  - `do StageDirector.wait(0.5)` 停顿；`do StageDirector.shake_camera(4, 0.4)` 震屏
  - `do StageDirector.flash(Color(1,1,1,0.8), 0.3)` 白闪；`do StageDirector.notify("……")` 提示条
- **改完 .dialogue 必须让 Godot 重新导入一次**（打开一次编辑器或跑一次 --import），否则跑的是旧编译结果。

## 六、世界地图（FF7 式）

`scenes/world/worldmap.tscn`（烘焙产物，可编辑）+ `worldmap_build.gd`（建造脚本）。
- **地点=LocationGate 节点**（World/Locations 下），检查器里配：目标场景 / 落点标记 / 解锁flag / 锁门文案
- **锁门机制**：`unlock_flag` 填剧情标记名，标记未置位 → 走近弹 locked_text；置位后（如老校长对话给 `allowed_up_mountain`）→ 切换场景
- **落点**：场景根下 Marker2D（FromTown / FromCrater / FromWorld），切场景前 `Game.pending_spawn` 记名字，到达后自动摆位
- 小镇北出口 → 自动进世界地图；世界地图走进小镇标记 → 回镇

## 七、触屏操作（手机）

`scenes/ui/hud.gd` 里 `_build_touch()`：
- **左下摇杆**：驱动标准 move_* 动作的模拟强度——键盘/摇杆/手柄共用同一套玩家代码
- **右下四键**：弹弓 / 对话(E) / 攻击(X) / 背篓(Tab)，菱形排布
- 横屏已配置（sensor_landscape），640×360 + keep 缩放 → 全面屏自动左右黑边
- `SHOW_TOUCH_UI = true` 常显（桌面用鼠标模拟触摸即可测试）；要改成"仅触屏设备显示"改这一处
- **Android 打包**（后续）：项目设置里方向已就绪，导出时配 Keystore 即可

## 九、碰撞分层（项目设置里已命名）

| 层 | 名字 | 谁在用 |
|---|---|---|
| 1 | 世界碰撞（墙/房/树/水） | 房、树、栅栏、边界墙、井 |
| 2 | 可交互（NPC/井/木牌） | 各交互感应区 |
| 3 | 玩家 | 玩家身体 |
| 4 | 敌人（野猪等） | 野猪身体；玩家攻击框与弹弓对着它 |

新敌人/新交互物照抄现有节点分层即可。
