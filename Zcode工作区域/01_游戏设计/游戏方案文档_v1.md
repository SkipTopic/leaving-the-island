## 1. 剧情正典（定稿摘要）

### 1.1 真相结构（防剧透分层：玩家的三段认知）

| 阶段 | 玩家以为 | 实际情况 |
|---|---|---|
| 阶段一（序章~上山） | 岛民小镇、镇民被"火山诅咒"变透明、两年前来了个傲慢的飞行员住进研究社、如今火山爆发全怪他 | ——（全为主角视角） |
| 阶段二（办公区~矿车） | 山里藏着那个飞行员的实验室 | 镇上没有别人；名单上36人全撤离且**没有主角** |
| 阶段三（揭示~结局） | —— | 主角就是"两年前坠机的飞行员"；镇民全是他的幻想；夜里那个"他"也是他；火山是夜里人格蓄意引爆的 |

### 1.2 时间线（全部收敛在约两年内）

1. **约2年前**：美国在莫尼点的秘密岛（气候武器研究）因"战争结束+项目无用+电磁风暴将至"三重原因，下令**一天之内全员撤离**（36人）。设备没关，全自动运转。
2. **几天~一个月后**：主角**肯·卡特**（22岁，[待确认①]）擅自驾机飞越太平洋，误入电磁风暴区坠岛。自动系统记录了坠机，**无人来救**。他头部受伤失忆，误以为自己是土生岛民。
3. **两年间**：白天=失忆的"镇长"与幻想镇民生活；夜里=**另一个他**醒着，两年学会维护全岛设备、翻遍档案、知道全部真相，一直在研究离开的方法。
4. **游戏开始**：夜里人格引爆火山（撑开电磁风暴、打开72小时通讯窗口，日志留下"对不起"）→ 主角提刀上山 → 真相 → 电台抉择。

### 1.3 人物表

| 人物 | 性质 | 说明 |
|---|---|---|
| 主角（白天） | 玩家操控 | 失忆飞行员肯·卡特，自认为24岁的岛民"镇长" |
| "晚上的人" | 不可玩，日志/录像揭示 | 夜里醒着的同一具身体，知道全部真相 |
| 陈婆 | 幻想镇民 | 小卖部老板娘，橘子糖，唠叨热心 |
| 六叔 | 幻想镇民 | 渔民，硬汉，房梁救他的人（记忆） |
| 老校长 | 幻想镇民 | 认字/讲古，实为识字卡片=研究站扫盲教具T-07 |
| 阿豆 | 幻想镇民 | 8岁小孩，"送"他弹弓（实为空屋捡的） |
| 阿蓝 | 幻想镇民 | 会堂钢琴师，白裙子，"我今天穿了很好看的白裙子" |
| "飞行员" | 幻想中的他者 | 主角把自己的坠机记忆错安到"别人"头上，全程无名 |

### 1.4 世界规则（玩家需要"习以为常"的设定）

- **透明镇民**：镇民半透明，但**手持物品不透明**（悬空的扫帚、钢笔、篮子），马车自己会跑。他们只能干轻活，**重活/出镇的事都靠主角**——这就是"镇长"的由来，也是任务系统的发布逻辑。
- **诅咒传说**：镇民透明是因为"主角小时候火山里的人下了诅咒"。主角**记得诅咒前后对比**（比如小时候摸过六叔的手）。这个传说也是主角自己编的。
- **夜规则**：夜里不可玩。夜的存在通过：日志、监控录像、物品被动过的痕迹、"灯跟着人走"的演出暗示。
- **电磁风暴**：岛与外界隔绝的原因；罗盘打转、没有船。72小时通讯窗口=结局成立的前提。

## 2. 游戏流程（章节结构）

> 章节即地图，完全按八章稿"上山的路"展开；服务区=存档点+补给站。

| **第三章 镇区线** | 地下矿车→自家床底→空镇 | 轻互动演出（"握杆，缓推"）+ **空镇巡礼**（检视互动：6个地点，每处一段独白） | **揭示核心**：街上无人→小卖部罐头码齐"像给一个人备的"→六叔的船没有鱼腥味→识字卡片（字典封底：岛站资产T-07）→坟头无字→**镇公所名单：36人全撤离，没有我** → 街心喊名字，无人应 | 飞行记录仪（回收） |
| **终章 72小时** | 办公区→通讯机房 | 解谜收尾+演出 | 矿车返程→读飞行记录仪（自动记录：坠机，无人来救）→档案里**自己的照片和真名**→两年《值班日志》全是"正常"，爆发前夜"**对不起**"，最后一页"**别怕。门都是我给你留的。红门别开。——晚上的人**"→监控录像（从头到尾只有一个人）→ 挑战信号响起 → **【说 / 不说】** | —— |

## 3. 核心系统设计

### 3.1 控制与战斗（轻战斗）
- 8方向移动（WASD/手柄左摇杆），Z/J=交互&确认，X/K=攻击（砍刀三段挥砍+短促前顶），C/L=弹弓（按住瞄准松开放箭，消耗石子），Tab/I=背篓，Esc=菜单/暂停。
- **敌人只有野兽**：野猪（山林冲撞）、低飞鸟（俯冲啄击）、爆发落石（环境伤害）。敌人工AI用简单状态机（巡逻/警觉/冲撞/逃跑），**demo阶段不引入行为树插件**，正式版再评估 LimboAI/Beehave。
- 无人类boss战；"三百回合"的镜像演出改为终章**录像揭示**（监控画面里一个人对空气搏命——轻战斗版本下这场戏用演出而非战斗呈现）。

### 3.2 血条与死亡
- HP=20，顶部左侧心形/长条血条（像素UI）。
- 受伤：无敌帧0.8s+击退+屏幕轻震+红闪。
- **死亡（昏倒）叙事包装**：眼前一黑→"醒来时我躺在自己床上，耳边好像有人念叨'你这个傻孩子'"→回最近存档点（家/服务区/办公区）复活，HP=10，敌人重生，进度保留。无其他惩罚（demo）。

### 3.3 背篓（背包）
- 12格网格，Kyrises 16x16 图标放大2x使用。
- 道具：压缩饼干（+8）、橘子糖（+3，"陈婆的糖"特殊描述）、生鱼（+2，钓鱼小玩法产出[可选]）、火柴（照明解谜：隧道/夜间室内）、手电（服务区获得）、水壶（装饰+剧情）、字典（关键道具：解锁"认字"检查项——看懂路牌/手册/电脑的前提！）、弹弓+石子、岛内公路图（=地图UI）。
- **字典=解谜钥匙**的设计让"认字"这条叙事线变成玩法（老校长的教导→真正用上）。

### 3.4 对话系统
- 插件：**Dialogue Manager**（nathanhoad）。透明镇民对话时：头顶冒对话气泡（无名字色块→名字以"？？？"或悬空符号表示？[待确认②]），对话框底部悬浮显示其"持有物"（扫帚/钢笔的抖动小动画）。
- 镇民台词分两层写：日常层（反复闲聊、诅咒传说、飞行员八卦）+ 主线层（任务/剧情推进）。揭示后回到镇上，**所有镇民消失**，只剩风声（结局一的世界照旧运转却空无一人——视觉冲击）。

### 3.5 时间与存档
- **无实时时钟**（[待确认③]）：剧情驱动昼夜，进入夜晚=黑屏转场"我又睡了个好觉"。夜里不可玩。
- 存档：3个手动槽+1自动槽；服务区/家/办公区=存档点（用"值班日志"文案包装："水循环，正常。"）。JSON序列化：玩家状态、任务flag、已收集道具、剧情进度。
- 转场：SourceCode.zip 里的 `transition.gdshader`（黑屏渐变）直接接入场景切换。

### 3.6 揭示演出（第三章为核心，逐点互动）
矿车（按住推进，"握杆，缓推"）→ 爬梯→ 床底钻出 → 六个检视点（街/小卖部/船/老校长屋/坟/镇公所）→ 喊名字（按键连按喊五个名字，只有风声）→ 矿车返程 → 记录仪→照片→日志→录像（雪花点画面，一个人）。全程无战斗，纯演出+独白，是demo的情感高潮。

## 6. 美术方案

- **像素基准：32×32**。人物=Pipoya免费角色32x32；世界=Pipoya World Tileset 32x32（草/道/森/海/山齐全）；小镇日夜=TILESET VILLAGE TOP DOWN（自带DAY/NIGHT两套！）；山路/矿车段=Tiny RPG Mountain+Forest（16x16素材2x整数放大混用）；物品图标=Kyrises 16x16（2x）。
- **透明镇民**：镇民 sprite 挂半透明 shader（alpha≈0.45+微微色散）；**手持物为独立不透明Sprite**（悬浮跟随骨骼点，自带轻微浮动动画）；Pipoya捏人器自带 **Ghost001** 幽灵皮肤，可直接拿来用。
- **需要自绘/改绘**（我来画）：主角24年岛民造型（用捏人器拼+改色）、"晚上的人"（同体换深色披肩/夜视配色，仅录像中出现）、矿车（2~3帧）、UI框/血条/背篓格、路牌与海报贴图（"欢迎登岛。山顶见。"等中文像素牌）、红门封条。
- **中文字体**：Fusion Pixel Font（开源 OFL，12px像素中文，GitHub: TakWolf/fusion-pixel-font）。
- 色调分幕：小镇=暖白日常 → 爆发=橘红灰黑 → 上山=冷蓝 → 揭示=灰蓝极简 → 结局一=暖阳 → 结局二=晨光。
