## 交付内容

### 1. 序章·火山爆发演出（正典时间线补全）
正典顺序：日常 → 半夜爆发 → 全镇决定上山 → 收拾行囊。此前游戏里爆发只是老校长口头带过。

- **流程**：我家床新增检视点「睡下」（`Prop_床`）→ 黑屏 → 爆发独白（第四章语料：闷响/橘光/黑雪是热的/
  六叔房梁救人/眉骨疤来历）+ 震屏×2 + 火光闪光×2 → 淡入天亮 → 晨段（窗户还亮着灯/陈婆"上山讲理"/
  "我去吧"/老校长字典）→ `allowed_up_mountain` 置位 → 通知"上山的路已经通了"。再睡 = 回笼觉小段。
- **语料文件** `resources/dialogue/town/eruption.dialogue`（sleep/not_yet/lay_down/eruption/morning/nap 六段）。
- **编排** `home_root.gd`：`sleep_requested` flag（床检视点置位）→ root 接管黑屏/淡入/气球三段。
  演出中 `Game.state=CUTSCENE`，门垫传送被状态锁挡住。
- **正典顺序修正**：老校长首段对话**不再直接解锁火山口**（原 M2 简化），改为爆发晨段解锁——
  玩家必须先经历爆发才会上山，与八章稿一致。
- 爆发后 `eruption_seen` 常驻：小镇出门即灰天黑雪（见下）。

### 2. 灰烬/黑雪粒子系统（M2 打磨清单）
- **`scenes/fx/ash_fall.tscn` + `ash_fall.gd`**（新组件）：CPUParticles2D 封装，惯例挂在玩家头顶
  (0,-230) 跟随视角、全局坐标下落；@export 全可调：density（每秒生成数）/flake_color/wind/width/flake_texture。
  preprocess=6 进场景即有半空灰。
- **三处应用**（全部运行时按 flag/场景挂载，节点名为 AshFall）：
  - 小镇（`eruption_seen` 后）：灰天 CanvasModulate(0.68,0.64,0.66) + 黑雪 ash_flake 36/s —— town_root
  - 空镇揭示（夜色）：稀疏冷灰 12/s —— reveal_root
  - 山道：**越往北（近山口）越浓**（6→44/s 平方曲线），颜色随浓度变深 —— mountain_root
- 自绘贴图：ash_flake(黑雪片 10×7)/ash_speck(烬点 5×5)，白色底便于运行时调色。

### 3. 隧道光斑美化（M2 打磨清单）
- `gen_pixel_art.gd` 新增 `_gen_light_spot()`：128×128 径向平方衰减 + **2×2 Bayer 抖动量化 5 档**——
  像素风的光有了颗粒感（替代原 GradientTexture2D 平滑渐变）。
- mountain_root：光斑贴图换 `light_spot.png` + 火苗抖动（能量 1.2 ± 双正弦起伏）。
- 截图验收：`00_思考过程/M4_隧道光斑.png`（抖动光环效果显著）。

- import 0 错误、烘焙 6/6、冒烟 **73/73 PASS**（+9：eruption.dialogue、灰烬场景联动、床检视点、
  山道灰烬在场、爆发演出全链 flag、爆发后小镇灰天+黑雪；老校长断言按新正典反转为"仍锁"）。
- 截图：M4_爆发后小镇 / M4_隧道光斑 / M4_山口灰烬（00_思考过程）。
- 踩坑记录：
  1. **多场景同活的测试环境里 `get_first_node_in_group("player")` 会拿到别的场景的玩家**——
     粒子挂错人。root 脚本一律改为 `_scene_player()`：先 `find_child("Player")` 本场景优先，
     group 兜底（真实单场景游戏行为不变）。
  2. CPUParticles2D 预处理(preprocess)粒子是**全局坐标**：瞬移玩家后预填充留在原地，
     新粒子飘进视野需 2~3 秒——截图/测试要等。
  3. `python` 往 .gd 插代码时吞过换行把两个语句粘成一行（Parse error），插入后应立即跑一次 headless 语法验证。
