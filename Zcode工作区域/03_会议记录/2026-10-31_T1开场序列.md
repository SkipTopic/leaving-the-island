## 关键决策（本轮自作主张的部分，请用户过目）
1. **家具自绘**而非用 TopDown Basic 现成杂物（包里只有石质桶/箱/墓碑，与暖色村庄风格不符）；墙体/地板用包内
   石砖（素材优先原则用在了能用的地方）。预览图：`00_思考过程/T1_家具预览.png`。
2. **电台结局回标题后再点开始 = 完整重播开场**（demo 语义：重开一遍；存档系统负责续玩）。
   如果想"结局后跳过开场"，一行 flag 就能加，等用户发话。
3. **外婆呼唤暂无配音/音效**（素材库没有合适的人声，字幕方案已可玩；后续可选：加一条风声/鸟鸣垫底）。
4. **进门回家暂不做反向传送**（交接文档标注"可选"，等室内有实际交互内容时再做）。

## 修错记录（新会话务必看，已同步交接文档§6）
1. **无头模式帧率漂移 → 测试改墙钟**：`_drive_dialogue` 原为 200 帧预算，但对话突变演出（StageDirector.wait/
   move_npc）按物理帧+真实时间跑；无头无垂直同步，帧率一漂（我的改动碰巧让帧率上去了）200 帧装不下 2.3 秒
   演出窗口，老校长对话被误判"卡死"（连续 3 次 FAIL，非偶发）。改为 30 秒墙钟预算 + 逐行推进
   （跳字→等 is_waiting→next，突变期间不堆 next）。**教训：无头测试里一切"等多久"都用 Time.get_ticks_msec()，别数帧。**
2. DM 本版 DialogueResource 没有 `get_titles()`，对应 API 是 **`get_cues()`**（cues 字典）。
3. gen_pixel_art.gd 曾被我用 Python 插入常量时算错锚点插坏 LAMP——GDScript 报 Parse error 后用 Read+Edit 修复。
   **教训：往 .gd 里程序化插入代码块，锚点计算要先打印确认。**
4. ASCII 像素画行宽不一致会被透明填充破坏右边框——写了个校验脚本（逐常量查行宽），MAP_ITEM 顺手修了一处遗留短行。
